# E-Commerce React

A responsive e-commerce website built with React, featuring product browsing, cart management, checkout, user account pages, and API integration.

## Features

- Browse products fetched from an API
- Product cards and product listing
- Shopping cart
- Checkout page
- Login and Sign Up pages
- Account management UI
- Wishlist UI
- Responsive design
- Reusable React components
- Custom hooks for API data fetching

## Technologies

- React
- React Router
- JavaScript (ES6+)
- Tailwind CSS
- CSS
- REST API
